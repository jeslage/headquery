# @headquery/schema

TypeScript types and a dependency-free runtime check (`assertIrSchema`) for the headquery intermediate
schema (IR): the JSON content model that CMS plugins export and
[`@headquery/codegen`](https://www.npmjs.com/package/@headquery/codegen) turns into types.

The JSON Schema is in [`spec/ir/schema-v1.json`](https://github.com/jeslage/headquery/blob/main/spec/ir/schema-v1.json).

See the [repository](https://github.com/jeslage/headquery) for documentation. MIT licensed.
