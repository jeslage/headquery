## Requirements

- Node.js ≥ 20 in the frontend. Node ≥ 22.18 lets the CLI load a `headquery.config.ts`
  directly; on older versions `init` writes `headquery.config.mjs` instead.
- A CMS version supported by its plugin, listed on the CMS's overview page.
