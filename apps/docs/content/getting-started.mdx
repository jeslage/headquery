# Getting started (Statamic)

<Steps>

### Enable Statamic's REST API

Turn on the REST API in `config/statamic/api.php` and enable the resources you want to
query. Add the fields you want to filter on to `allowed_filters`. headquery only exports
enabled resources, and only `allowed_filters` fields can be used in `.where()`.

### Install the addon

```bash
composer require headquery/statamic
php artisan vendor:publish --tag=headquery-config   # optional
```

### Install the client

```bash
npm install @headquery/statamic
npm install -D @headquery/codegen
```

### Generate types

<Tabs items={["Same project", "Separate frontend repo"]}>
  <Tabs.Tab>
    ```bash
    php please headquery:schema --out=schema.json
    npx headquery-codegen --from schema.json --out src/cms.generated.ts
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    Enable the [schema endpoint](/statamic/schema-endpoint) on the CMS, then:

    ```bash
    npx headquery-codegen \
      --from https://cms.example.com/api/headquery/schema \
      --token "$HEADQUERY_SCHEMA_TOKEN" \
      --out src/cms.generated.ts
    ```
  </Tabs.Tab>
</Tabs>

Add `--check` in CI to fail when the generated file is out of date.

### Query

```ts
import { createStatamicClient } from "@headquery/statamic";
import "./cms.generated";

export const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });

const { data } = await cms.global("settings").get();
```

</Steps>

## Client options

| Option | Default | Description |
| --- | --- | --- |
| `baseUrl` | — | Origin of the CMS, e.g. `https://cms.example.com` |
| `apiPrefix` | `/api` | Matches Statamic's `statamic.api.route` |
| `token` | — | Sent as `Authorization: Bearer <token>` |
| `headers` | — | Extra headers for every request |
| `fetch` | `globalThis.fetch` | Custom fetch (SSR frameworks, tests, polyfills) |
| `fetchOptions` | — | Merged into every fetch call, e.g. `{ cache: "force-cache" }` or Next's `{ next: { revalidate: 60 } }` |

Per call, `.get({ signal, fetchOptions })` accepts an `AbortSignal` and fetch options
that override the client's.
