# Roadmap

1. **Statamic hardening:** test the addon against real Statamic installs, plus automated
   tests for the exporter, command and route.
2. **End-to-end tests:** run the JS client against a live Statamic instance in CI.
3. **More Statamic resources:** assets, users, multi-site helpers.
4. **Codegen:** `headquery.config.ts`, CI recipes for `--check`, ETag-aware fetching.
5. **Framework adapters:** `@headquery/vue` (composables) and `@headquery/react` (hooks),
   then Nuxt and Next.js integrations. They build on `@headquery/core`, so they work with
   every CMS.
6. **More CMSs:** Kirby (via a cacheable GET route in front of KQL), then Craft.
