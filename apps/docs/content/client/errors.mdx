# Errors

All errors extend `HeadqueryError` and are exported from `@headquery/statamic` (and
`@headquery/core`).

| Error | When | Properties |
| --- | --- | --- |
| `HeadqueryHttpError` | The CMS answered with a non-2xx status | `status`, `url`, `body` (parsed JSON or raw text) |
| `HeadqueryNetworkError` | No usable response: network failure, CORS, abort, invalid JSON | `url`, `cause` |

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
import { HeadqueryHttpError } from "@headquery/statamic";

try {
  await cms.collections("blog").find("missing").get();
} catch (error) {
  if (error instanceof HeadqueryHttpError && error.status === 404) {
    // not found
  }
  throw error;
}
```
