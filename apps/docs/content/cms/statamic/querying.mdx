# Querying

`@headquery/statamic` wraps Statamic's [REST Content API](https://statamic.dev/rest-api).
Every builder compiles to a plain `GET` request. The filter, sort and field names are the
same ones the API itself uses.

The examples on this page are type-checked against types generated from a sample schema:
a `blog` collection, a `tags` taxonomy, a `settings` global set and an `assets` container. Hover over the code
to see the inferred types.

Every method is named after the first segment of the REST path, as in Statamic's API. It
takes a handle and starts a query, like `Entry::query()->where('collection', 'blog')`.

| Method | Returns | One item via `.find(key)` |
| --- | --- | --- |
| `collections(handle)` | entries: `GET /collections/{handle}/entries` | id or slug |
| `taxonomies(handle)` | terms: `GET /taxonomies/{handle}/terms` | slug |
| `assets(container)` | assets: `GET /assets/{container}` | path |
| `globals()` / `globals(handle)` | all sets: `GET /globals` | – (`globals(handle)` is `GET /globals/{handle}`) |
| `navs()` | navigations: `GET /navs` | – |

Trees: `collections(handle).tree()` (structured collections) and `navs(handle).tree()`.

## Collections

```ts twoslash
import "./generated/cms.generated";
// ---cut---
import { createStatamicClient } from "@headquery/statamic";

const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });

const posts = await cms
  .collections("blog")
  .where("featured", true)
  .sort("-date")
  .limit(10)
  .get();

posts.data[0]?.title;
//             ^?
```

`GET /api/collections/blog/entries?filter[featured:is]=true&limit=10&sort=-date`

`.find(idOrSlug)` fetches a single entry (`GET /api/collections/blog/entries/hello-world`).
It resolves to `null` when the entry doesn't exist or isn't published:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const post = await cms.collections("blog").find("hello-world").fields(["title", "content"]).get();
if (post) {
  post.data.title;
  //        ^?
}
```

`.find()` uses Statamic's single-item endpoint, which ignores filters, sort and pagination,
so it is only available directly after `collections(…)`. Its options (`.fields()`, `.site()`)
come after it. To get the first match of a filter instead, use `.where(…).first()`: it needs
the field in `allowed_filters` and also resolves to `null`.

## Filters

`.where(field, value)` means the `is` condition. Pass a condition as the second argument
for anything else:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
cms.collections("blog")
  .where("title", "contains", "release")    // filter[title:contains]=release
  .where("slug", "in", ["a", "b"])          // filter[slug:in]=a|b
  .where("featured", "exists");             // filter[featured:exists]=true
```

| Kind | Conditions |
| --- | --- |
| Scalar | `is` `not` `contains` `doesnt_contain` `starts_with` `doesnt_start_with` `ends_with` `doesnt_end_with` `gt` `gte` `lt` `lte` |
| List | `in` `not_in` (values joined with `\|`) |
| Presence | `exists` `doesnt_exist` |

Statamic only accepts filters on fields listed in the collection's `allowed_filters`.
With generated types, other fields are a type error:

```ts twoslash
// @errors: 2769
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
cms.collections("blog").where("reading_time", 3);
```

## Sort, pagination, sites

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const page2 = await cms.collections("blog")
  .sort("-date", "title")   // sort=-date,title (later calls replace earlier ones)
  .limit(20)
  .page(2)
  .site("de")               // multi-site
  .get();

page2.meta.total;
page2.links.next;
```

`.first()` sends `limit=1&page=1` and returns the first item or `null`.

## Selecting fields

`.fields()` sends `fields=` and narrows the result type to the selected fields:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const { data } = await cms.collections("blog").fields(["title", "hero"]).get();
//      ^?
```

## Taxonomies

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const tags = await cms.taxonomies("tags").where("title", "starts_with", "j").get();
const tag = await cms.taxonomies("tags").find("javascript").get(); // null if missing
```

## Globals

`globals(handle)` fetches one global set (`GET /globals/{handle}`), `globals()` all of them
(`GET /globals`). In the list, `handle` tells the sets apart:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const settings = await cms.globals("settings").get();
settings.data.site_name;
//            ^?

const all = await cms.globals().get();
for (const set of all.data) {
  if (set.handle === "settings") set.social;
}
```

## Collection trees

`collections(handle).tree()` fetches the page tree of a structured collection
(`GET /collections/{handle}/tree`), e.g. a pages collection. Every page is an entry of the
collection plus `entry_id` (equal to `id`); unpublished entries are left out.

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const { data } = await cms.collections("pages").tree().maxDepth(2).fields(["title", "url"]).get();

for (const { page, depth, children } of data) {
  page.title;
  //   ^?
}
```

- `.maxDepth(n)`, `.site(handle)` and `.fields([...])` work like for navigation trees.
- `.where(...)` filters with the collection's `allowed_filters`, per level: a page that
  doesn't match is dropped together with its children.
- `tree()` only exists for structured collections (the schema marks them), and only directly
  after `collections(…)`. On other collections Statamic answers 404.

## Navigation

`navs(handle).tree()` fetches a navigation tree (`GET /navs/{handle}/tree`). Enable it in
`config/statamic/api.php` under `resources.navs`.

Each page is either a plain link (`entry_id: null`) or a linked entry: Statamic then returns
all of the entry's fields, and `entry_id` holds the entry's id (`id` is the nav item's id).
Fields of the navigation's blueprint are on every page.

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const { data } = await cms.navs("main").tree().maxDepth(2).get();

for (const { page, depth, children } of data) {
  if (page.entry_id !== null) {
    page.reading_time; // an entry of a linked collection
    //   ^?
  } else {
    page.url; // a plain link
  }
}
```

- `.maxDepth(n)` sends `max_depth`, `.site(handle)` picks a site.
- `.fields([...])` narrows the pages; keep `entry_id` if you need to tell links and entries apart.
- `cms.navs()` lists all navigations (`GET /navs`).

To fetch several resources for a layout, start the requests together. Each is a plain,
cacheable GET:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const [navigation, settings] = await Promise.all([
  cms.navs("main").tree().fields(["title", "url", "entry_id"]).get(),
  cms.globals("settings").get(),
]);
```

## Assets

`assets(container)` lists the assets of a container (`GET /assets/{container}`). It's the
REST equivalent of `Asset::query()->where('container', …)`: filters, sort, pagination and
`fields` work like for entries. Enable it in `config/statamic/api.php` under
`resources.assets`.

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
// Asset::query()->where('container', 'assets')->where('basename', 'hero.jpg')->first()
const hero = await cms.assets("assets").where("basename", "hero.jpg").first();

const icons = await cms
  .assets("assets")
  .where("folder", "icons")
  .sort("basename")
  .fields(["url", "alt", "width", "height"])
  .get();
icons.data[0]?.width;
//             ^?
```

`.find(path)` fetches one asset by its path relative to the container root
(`GET /assets/{container}/{path}`), or `null` if it doesn't exist. Folder slashes stay in
the URL:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const logo = await cms.assets("assets").find("icons/logo.svg").get();
// GET /api/assets/assets/icons/logo.svg
logo?.data.is_image;
//         ^?
```

Assets include Statamic's system fields (`HqAssetBase`: `path`, `basename`, `folder`, `url`,
`size_bytes`, `width`, `height`, `mime_type`, …) plus the container blueprint's fields.
`width`, `height` and `ratio` are `null` for files that aren't images or videos. Asset
*fields* on entries are smaller (`HqAsset`: `id`, `url`, `permalink`, `api_url`, `alt`).

## Immutability

Every builder method returns a new query, so a partial query can be reused safely:

```ts twoslash
import "./generated/cms.generated";
import { createStatamicClient } from "@headquery/statamic";
const cms = createStatamicClient({ baseUrl: "https://cms.example.com" });
// ---cut---
const blog = cms.collections("blog").sort("-date");

const featured = blog.where("featured", true).limit(3);
const latest = blog.limit(10); // not affected by `featured`
```
