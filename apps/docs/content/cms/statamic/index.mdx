# Statamic

headquery wraps Statamic's [REST Content API](https://statamic.dev/rest-api) with typed query
builders, and a small addon exports your content model so codegen can generate the types.

| Package | Registry | Purpose |
| --- | --- | --- |
| `@headquery/statamic` | npm | Typed client for the REST Content API |
| `headquery/statamic` | Packagist | Addon: exports the content model via `php please headquery:schema` or an endpoint |

**Requirements:** Statamic 5 or 6 with Pro (the REST API is a Pro feature), PHP ≥ 8.2.

**Supported resources:** collection entries and trees, taxonomy terms, globals, navigation trees, assets, users,
forms and sites. Metadata endpoints and `/ping` work through [`cms.send()`](/cms/statamic/querying#other-endpoints).
